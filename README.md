# WindowsLightOptimizer
Herramienta gráfica avanzada y ultraligera desarrollada en Python (tkinter) diseñada para optimizar, limpiar y potenciar sistemas Windows. Cuenta con una interfaz moderna en modo oscuro, protocolos de limpieza segura de temporales, optimización de red TCP/IP y un Comando Maestro Extremo para exprimir al máximo el rendimiento
